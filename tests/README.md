# `tests/` — Test Suite

This directory contains automated integration and unit test suites for `mind`.

## Files

| File | Purpose |
|---|---|
| `__init__.py` | Test package marker. |
| `test_integration.py` | Comprehensive test covering virtual screen buffer emulation (`pyte`), cross-platform PTY process spawning (`winpty`/Unix), embedded FastMCP tools (`list_workers`, `get_terminal_screen`, `send_terminal_input`, `interrupt_and_inject`, `get_agent_profile`), background SSE server runner, and Textual UI components. |
| `test_terminal_buffer.py` | Unit tests for `TerminalBuffer`: 2D character grid emulation (`pyte.HistoryScreen`), Run-Length Encoding (RLE) character batching, `rich.style.Style` object caching, frame-level render cache retention, $O(1)$ version counter and content presence verification, clean ANSI-free plain text export for MCP tools, TrueColor/256-color parsing, and thread-safe concurrent feeds and reads. |
| `test_pty_engine.py` | Unit and integration tests for the async PTY engine: Windows ConPTY scancode/dead-key sanitization, stray `\xe0` byte filtering, zero-polling event-driven async streams (`proc.stream()`), dynamic output listeners, safe interrupt signals, and recursive zombie process prevention via `psutil`. |
| `test_vim_modal.py` | Unit tests for the Vim Modal System, visible worker tab bar, split-view toggling ('s'), agent task assignment dispatcher, and PTY input isolation. |
| `test_credentials_isolation.py` | Tests for multi-slot authentication persistence, environment directory isolation (`AGY_SLOT`, `ANTIGRAVITY_GEMINI_DIR`, `ANTIGRAVITY_APP_DATA_DIR`), cross-process credential mutex locks, BOM-safe token decoding, and non-destructive shutdown. |
| `test_auth_refactor.py` | Unit tests for modular authentication architecture: BOM sanitization, claims decoding, expiration detection, mock storage, and token lifecycle manager. |
| `test_auth_vault.py` | Comprehensive tests for cross-platform credential vault: Linux encrypted file vault with `chmod 0600` permissions, SecretService fallback, inter-process mutex timeout locking, raw JWT / UTF-16 BOM validation, and bidirectional Dual-Sync between instance and central token paths. |
| `test_directives_and_idle.py` | Unit tests for passive idle startup, Markdown directive file persistence in `~/.mind/directives/`, in-app editing, event-driven coordinator alarm pipeline (`CoordinatorAlarmPipeline`), intelligent IDLE prompt detection (`is_idle_prompt`), single-threaded debouncing without thread churn, dynamic status summary extraction, visual header badges (`⚡ Worker-X Finished (Idle)` and `🚨 Assistance Needed`), and coordinator terminal injection. |
| `test_usage_monitor.py` | Unit and integration tests for Accounts Quota & Usage Monitor Engine: high-precision graphic progress bar generation (`[████████░░] 80%`), semantic color indicator codes (green, yellow, red), robust timestamp parsing, SQLite conversation history & interaction log aggregation, hourly and weekly quota calculation, warning and throttled state detection, multi-slot discovery, and CLI command execution (`mind usage`, `mind -u`, `--json`). |
| `test_mcp_integration.py` | Comprehensive unit and integration tests for High-Performance Async MCP Server: tool registrations, `list_workers` with linked accounts and quota statistics, `get_terminal_screen` with version-aware memory caching, non-blocking input dispatch via `send_terminal_input`, safe priority interruption via `interrupt_and_inject`, `check_account_quotas` multi-slot and single-slot inspections with progress bars and JSON output, and `MCPServerRunner` non-blocking background lifecycle (`wait_for_ready=False`). |
| `test_agent_discovery_isolation.py` | Unit and integration tests for Dynamic Agent Discovery and Slot Isolation: CLI subcommand inspection (`agy agents`), Windows `%LOCALAPPDATA%\agy\bin` and Linux POSIX binary path discovery, natural numerical sorting (`agy1` .. `agy10`), fallback handling, slot isolation environment variables (`USERPROFILE`, `HOME`, `AGY_SLOT`, `AGY_INSTANCE_DIR`), anti-nesting home resolution (`get_real_user_home`), instance directory provisioning matching PowerShell `agys` (`Initialize-AgyInstance`), and `agys` PowerShell compatibility verification helpers. |
