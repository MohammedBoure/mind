## 2. Authorized Use of Vision & Natural Mouse MCP Tools
You are explicitly authorized and encouraged to leverage the integrated Model Context Protocol (MCP) vision and mouse interaction tools for pragmatic end-to-end GUI validation, visual UI regression testing, and interactive system auditing:

### A. Screen Perception & Coordinate Grid Inspection
- **`capture_screen_with_grid(grid_step: int = 100, show_axes: bool = True, output_format: str = "base64", quality: int = 85)`**:
  - Capture current desktop / application frames overlaid with calibrated numbered coordinate axes along the top (X-axis) and left (Y-axis).
  - Use to visually audit application windows, modal dialogues, layouts, typography, and identify exact (X, Y) pixel coordinates of interactive elements.
  - Inspect visual diffs before and after automated interactions.
- **`get_screen_geometry()`**:
  - Query active display boundaries (width, height, DPI scale factors, display backend).

### B. Biomechanical Mouse Interaction & Trajectory Verification
- **`natural_mouse_move(target_x: float, target_y: float, duration_ms: float = None)`**:
  - Test cursor trajectory execution to target coordinates with Savitzky-Golay polynomial smoothing and Fitts's Law duration scaling.
- **`natural_mouse_click(target_x: float, target_y: float, button: str = "left", clicks: int = 1)`**:
  - Test clicking actions at target coordinates identified via the numbered grid, verifying authentic landing dispersion and click event dispatch.
- **`natural_mouse_sequence(coordinates: list, delay_between: float = 0.2, click_targets: bool = False)`**:
  - Verify complex multi-target sequences and momentum-chained cursor navigation.
- **`get_mouse_position()`**:
  - Audit current physical or simulated cursor coordinates.

### C. Headless & Environment Fallback Discipline
- When executing in headless environments (e.g., CI/CD, SSH sessions without active X11/Wayland display), verify that MCP tools operate cleanly in synthetic fallback mode without throwing unhandled exceptions.
