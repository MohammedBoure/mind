# `src/mind/core/` — Terminal & Process Multiplexing Core

This directory provides the low-level pseudoterminal (PTY) abstractions, virtual screen buffer emulation, and worker process lifecycle management for the `mind` multi-agent orchestrator.

## Files

| File | Purpose |
|---|---|
| `__init__.py` | Public exports for core classes and helper factories. |
| `alarm_pipeline.py` | Event-Driven Primary Coordinator Alarm Pipeline & Intelligent Single-Thread Debounce Engine (`CoordinatorAlarmPipeline`, `is_idle_prompt`, `extract_status_summary`). Monitors active worker terminal processes, detects transitions to interactive IDLE prompts via a lightweight single-threaded debouncer without CPU exhaustion or continuous timer thread churn, filters Vim statuslines and model badges to prevent echo loops, emits instant alarms to the Primary Coordinator and MCP subscribers, and formats factual event summaries without synthetic prompt injections. |
| `terminal_buffer.py` | Thread-safe 2D virtual character grid and scrollback history buffer using `pyte.HistoryScreen` and `rich.text.Text`. Features scrollback history retrieval (`get_history_count`, `scroll_offset` integration), high-performance Run-Length Encoding (RLE) character batching, `rich.style.Style` object caching (preventing memory bloat), frame-level render caching to eliminate redundant re-rendering of unchanged frames, instant $O(1)$ version counter tracking and visible content presence detection, and clean ANSI-free plain text export functions (`get_screen_text`, `get_plain_text`, `export_clean_text`) for MCP tool inspection while preserving full formatting and colors for Textual TUI. |
| `pty_process.py` | High-performance, event-driven cross-platform PTY engine supporting Windows (ConPTY via `pywinpty` with dead-key blocking, scancode translation, and stray `\xe0` byte filtering), Linux/Unix (native `openpty`/`termios` with `epoll` selector reader, controlling terminal `os.login_tty` attachment for SIGWINCH resize propagation, race-condition protected cancellation wakeup), zero-polling event-driven async streams (<1ms latency), `SIGINT`/`Ctrl+C` propagation, and zombie process prevention via `psutil`. |
| `agent_discovery.py` | System-wide dynamic agent discovery (`discover_system_agents`, `discover_agent_slots`, `get_agys_instances_dir`) and slot isolation engine (`build_slot_isolation_env`, `initialize_slot_instance`). Discovers all installed CLI agents (`agy1`, `agy2`, `agy3`, `agy11`, `agy51`, `agy100`, `agy151`, etc.) via `agys -l` multi-instance CLI registry table, host multi-instance directory (`$AGY_INSTANCES_DIR` / `~/.local/share/agy-instances/`), `agy agents` / `agy agent`, Windows slot launchers (`%LOCALAPPDATA%\agy\bin`), Linux/POSIX system paths (`/usr/local/bin`, `/usr/bin`, `~/.local/bin`), `~/.gemini/instances`, and `~/.gemini/tokens`. Automatically discards multi-instance orchestrator tools (`agys`, `agy`), applies natural numeric sorting, resolves slot instance directories and OAuth tokens (`antigravity-oauth-token` / `token.json`), isolates slot environments (`USERPROFILE`, `HOME`, `AGY_SLOT`, `AGY_INSTANCE_DIR`), prevents nested home conflicts via `get_real_user_home`, provisions directories matching PowerShell/POSIX `agys`, and provides `agys` integration and compatibility verification helpers (`verify_agys_compatibility`, `generate_agys_command`). |
| `credentials.py` | Backwards-compatible facade forwarding credential management, cross-process mutex locking, and slot environment setup to `mind.core.auth`. |
| `auth/` | Modular authentication package containing models, validator, cross-platform keyring backends (Windows Credential Manager `gemini:antigravity`, Linux SecretService / Keyring, and encrypted `chmod 0600` file vault), inter-process mutex locking (`Global\AgyCredentialMutex` / `.credential.lock`), and bidirectional Dual-Sync token manager. |
| `directives.py` | Externalized Directives & Hot-Reload Engine (`DirectivesWatcher`, `ensure_default_directives`, `resolve_directive_path`, `extract_target_from_path`, `get_instance_gemini_path`, `load_directive`, `save_directive`, `open_directive_in_editor`). Prioritizes agent instance `.GEMINI.md` files located at `~/.local/share/agy-instances/<slot>/.gemini/.GEMINI.md` and workspace `.GEMINI.md`, removing all internal principles and synthetic directives. Features a background watcher (`DirectivesWatcher`) monitoring external file modifications, debouncing partial writes, and broadcasting hot-reload events. Provides cross-platform external editor launching (`os.startfile`, `xdg-open`, `open`, and `$EDITOR`). |
| `usage_monitor.py` | Accounts Quota & Usage Monitor Engine (`UsageMonitor`, `SlotQuotaUsage`, `QuotaStatus`). Monitors Antigravity worker slots (`agy1` .. `agyN`), calculates hourly and weekly remaining quotas, aggregates step counts from `conversation_summaries.db` and interaction logs from `history.jsonl`, evaluates throttle/warning states, generates high-precision graphical progress bars (`[████████░░] 80%`) with semantic color indicators (Green for plentiful, Yellow for warning, Red for throttled), and provides standalone CLI execution and Rich table rendering. |
| `terminal_manager.py` | Central `TerminalManager` orchestrator and `WorkerSession` model. Manages active `agy` worker and coordinator sessions, root launch working directory resolution (`get_launch_cwd`, `set_launch_cwd`), automatic slot credential isolation and restoration on startup, clean `principles: []` initialization without hardcoded directives, directives hot-reload listener synchronization, thread-storm debouncing, lazy worker lifecycle, CLI flags tuning, process restarting, and inter-agent interrupt dispatching. |
| `session_storage.py` | Persistent Session Management & Activity Telemetry Engine (`SessionRecord`, `load_all_sessions`, `get_session`, `save_session`, `delete_session`, `record_session_activity`, `get_default_sessions_path`, `load_global_config`, `save_global_config`, `update_global_config`, `update_session_worker_config`). Persists multi-agent orchestration sessions to `~/.mind/sessions.json` with per-worker slot and profile configurations (`agent_configs`), global app preferences to `~/.mind/config.json`, comprehensive live activity statistics (agent count, goal, active status, total steps, interaction count, working directory path, and last activity timestamps), and provides seed sessions fallback. |
