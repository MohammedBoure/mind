# Data Engineering & Training Pipeline

This directory contains data preparation, extraction, and deep learning training pipelines for the NaturaleMouseEvent AI engine.

## Subdirectories

- **`data_prep/`**: Telemetry parsing, filtering, monotonic validation, and `.npz` dataset generation scripts. See [data_prep/README.md](file:///D:/git/NaturaleMouseEvent/pipeline/data_prep/README.md).
- **`training/`**: PyTorch neural network training pipelines with scheduled sampling, kinematic memory, and multi-objective biomechanical loss functions. See [training/README.md](file:///D:/git/NaturaleMouseEvent/pipeline/training/README.md).

## Files

- **`__init__.py`**: Pipeline package initializer.
