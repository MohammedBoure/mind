# `src/mind/ui/` — UI Components & Screens

This directory contains all Textual-based UI widgets and screens for the `mind` TUI multiplexer.

## Files

| File | Description |
|---|---|
| `__init__.py` | Package init for the UI module. |
| `styles.tcss` | Global Textual stylesheet featuring a high-contrast Tokyo Night palette (deep indigo/slate canvases, vibrant accents), Zellij/Helix-inspired header and status bars with zero vertical clipping for single-line docks, soft rounded borders (`border: round`) on multi-line cards, smart visual separation between Coordinator and Worker panes, custom dialog styling for worker slot selection (`#select-worker-dialog`), and full compatibility with developer monospace fonts, Nerd Fonts, Unicode, and Arabic characters. |
| `session_picker.py` | Landing screen showing persisted orchestration sessions with live activity telemetry (agent count, active state, step counts, tasks, created & last active timestamps), Vim keyboard navigation (`↑↓/jk`), quick opening (`Enter`), deletion (`d`/`x`), disk refresh (`r`), and new session creation (`n`). |
| `new_session_modal.py` | Modal dialog for creating a new session (name, agent count, goal) with automatic instant persistence to `~/.mind/sessions.json`. |
| `select_worker_modal.py` | Dynamic Worker Agent Selection Modal (`SelectWorkerModal`): inspects and presents all installed multi-instance Antigravity agents (`agy1`, `agy2`, `agy3`, `agy11`, `agy51`, `agy100`, `agy151`, etc.) from host `agys` storage with real-time text filtering (`worker-search-input`), live token/account status badges (`● Ready`, `● In Use`, `○ Unauthenticated`), account email claims, full keyboard navigation (Up/Down/j/k, Enter, Esc), and returns chosen agent instance to spawn new worker tabs. |
| `clipboard.py` | Cross-platform multi-tiered clipboard synchronization engine (`copy_to_clipboard`, `get_clipboard_text`, `sanitize_clipboard_text`, `clear_clipboard`, `get_clipboard_history`). Features robust 5-tier fallback: `pyperclip`, Textual `App.copy_to_clipboard` (OSC 52), Win32 native Unicode API (`ctypes`), POSIX CLI utilities (`wl-copy`/`wl-paste`, `xclip`, `xsel`, `pbcopy`), and persistent in-memory buffer. |
| `workspace.py` | Main multiplexer workspace screen featuring a high-precision dual Vim modal system: **NORMAL Mode** (instant single-key command dispatch: `1..9` tab jumping, `h/l` cycling, `s` split-view toggling and full-screen expansion, `m` directive injection modal, `e` agent configuration modal, `c` new worker tab with dynamic `SelectWorkerModal` prompt, `x` tab termination, `y` clipboard yank, `d` in-app directive editor, `o` external editor, `q` quit, `?` help, `Tab` pane focus cycling) and **PTY_INTERACT Mode** (zero-delay raw stdin passthrough with instantaneous Leader exits via `Ctrl+B`, `F12`, or `Esc Esc` double escape within 350ms, while preserving bare single Escape for internal child Vim prompts). Features flexible Split View (permanent Primary Coordinator `#primary-pane` on left, interactive Worker tab switcher `#workers-pane` on right with focus-aware full-screen expansion), clean idle startup for Primary Coordinator without automatic initial prompts, unified project path propagation opening all worker agents on the exact path where `mind` was launched, dynamic worker instance assignment drawing sequentially from discovered host `agys` slots, interactive `SelectWorkerModal` dialog on adding new worker tabs, Lazy Spawning (launching only Coordinator and initial Worker at boot, auto-spawning subsequent workers on tab activation), directive hot-reload sync with visual toasts, and non-blocking MCP lifecycle management. |
| `terminal_tab.py` | Interactive terminal components: `TerminalScreenWidget` (with visibility-aware rendering, visual selection highlight styling `_apply_selection_styling`, terminal scrollback history navigation via mouse wheel, PageUp/PageDown, Home/End, mouse drag-selection with Auto-Copy on MouseUp, Right-Click copy of selection or recent buffer, global `Ctrl+Shift+C` and Normal-mode `y` yank shortcuts, event-driven output updates, seamless support for Arabic multi-byte ligatures and diacritics, shortcut triggers `Ctrl+M`, `Ctrl+E`, `Ctrl+O`, `Ctrl+D`, and Vim-over-Vim escape passthrough), `WorkerTerminalTab` (with Primary Coordinator role styling, instance identity & runtime CLI warnings), and `WorkerTabBar` (unclipped full-Unicode tab titles with live operational activity indicators: `●` running, `○` standby/lazy, `…` waiting input, `!` unread notifications, `||` paused, and `x` terminated). |
| `agent_config_modal.py` | Interactive Agent Configuration & Discovery Modal (`AgentConfigModal`): dynamically discovers installed system agents (`agy1`, `agy2`, etc.), assigns `--agent <name>`, tunes CLI flags (`--mode`, `--model`, `--effort`), provides in-app and external directive management, and updates tabs in real time. |
| `directive_editor_modal.py` | In-app modal text editor (`DirectiveEditorModal`) for inspecting, modifying, and saving agent behavioral Markdown guidelines directly within the TUI. Supports `Ctrl+S` (Save & apply), `Ctrl+O` (Open in system default editor), and `Esc` (Cancel). |
| `directive_modal.py` | Agent Assignment & Task Dispatcher modal (`DirectiveModal`): select target agent (Primary Coordinator or Worker 1..N), assign role, configure task priority (`high`, `critical`, `normal`, `low`), and dispatch prompt or interrupt directly into running PTY processes. |
| `header_bar.py` | Streamlined Zellij-inspired top bar (`HeaderBar`): fixed 1-line dock-top with brand logo (`mind`), active session name, active worker telemetry, Live Quota Badge (`#quota-pill`) displaying graphic progress bars with remaining percentage and color-coded status, and MCP server indicator. |
| `bottom_bar.py` | Multi-segment status bar (`BottomBar`): fixed 1-line dock-bottom with clickable mouse-interactive Action Pills, mode indicator (`NORMAL MODE` vs `PTY INTERACT`), and cross-platform PTY architecture badge (`ConPTY` on Windows / `POSIX PTY` on Linux/Unix). |
| `agent_pane.py` | Agent log pane widget — scrollable, color-coded log stream for agents with mouse click / right-click clipboard copying. |
| `interrupt_banner.py` | Visual toast alert banner for inter-agent message interruptions and directives. |
| `help_modal.py` | Help modal overlay showing the complete Vim modal navigation, tab controls, external & in-app directive shortcuts (`o / Ctrl+O`, `d / Ctrl+D`), and general keybindings. |
